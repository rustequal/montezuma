# MASM 1.25

Three files are needed to build the game, and they belong in this
directory:

```
MASM.EXE      Microsoft Macro Assembler 1.25
LINK.EXE      Microsoft 8086 Object Linker
EXE2BIN.EXE   converts the linked .EXE into a .COM memory image
```

They are kept here so that nobody has to go looking for them. Version
1.25 is old and hard to come by, and the byte-for-byte match is
verified with it.

Copies were taken from the PCjs software archive:
<https://www.pcjs.org/software/pcx86/lang/microsoft/masm/1.25/>
